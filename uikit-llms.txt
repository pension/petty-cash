# Getting Started & Global Configuration

## 1. Installation & Setup

To use `@pension/ui-kit` in your Vue 3 application:

### Install the package

Ensure you have access to the `@pension` registry and install:

```bash
npm install @pension/ui-kit
```

### Import Styles

You **must** import the package's compiled CSS in your main entry file (e.g., `main.js` or `main.ts`):

```javascript
import "@pension/ui-kit/style.css";
```

### Register the Plugin (Optional)

You can register all components globally:

```javascript
import { createApp } from "vue";
import UiKit from "@pension/ui-kit";
import App from "./App.vue";

const app = createApp(App);
app.use(UiKit);
app.mount("#app");
```

Or import components individually as needed (recommended for better tree-shaking):

```javascript
import { PoButton } from "@pension/ui-kit";
```

---

## 2. Tailwind CSS Styling

> [!NOTE]
> The custom **`po:`** prefix is **only used internally** within the `@pension/ui-kit` library codebase.
> In the applications where this library is imported and consumed, you **do not need the prefix**. Use standard Tailwind CSS utility classes.
>
> **Consuming Application Example:**
> `<div class="flex items-center gap-4 p-4">`

# Component Composition Patterns & Guides

This section provides the official templates and guidelines on how to combine `@pension/ui-kit` components together to build common UI pages, tables, modals, and search cards.

## 1. Core Page Layout

Use this template when creating new pages. It sets up a layout with a header, page title, actions area, and content card inside `PoContentArea`.

```vue
<template>
	<PoContentArea>
		<header class="lg:flex lg:items-end">
			<PoPageTitle
				class="grow"
				:stand-alone="true"
				label="Page Title"
				description="Page description, should be three lines of text."
			/>
			<div class="mt-5 lg:mt-0 shrink-0 gap-2 flex items-center flex-wrap">
				<!-- Page action buttons should go here -->
			</div>
		</header>
		<div class="space-y-2">
			<!-- Content goes here. you can change this area -->
			<PoCard> ... </PoCard>
			<!-- Content goes here. you can change this area -->
		</div>
	</PoContentArea>
</template>

<script setup lang="ts">
import { ref } from "vue";
import { PoContentArea, PoPageTitle, PoCard } from "@pension/ui-kit";

definePageMeta({
	layout: "main",
});

useHead({
	title: "Sample Page Title",
});

interface Props {}

withDefaults(defineProps<Props>(), {});
</script>
```

## 2. Standard Table

Use this pattern when displaying lists and tabular data using `PoTable`.

```vue
<template>
	<PoTable :thead="tableHead" :tbody="tableBody">
		<template #th="{ label }">
			<span v-if="'Action' !== label">{{ label }}</span>
			<span v-if="'Action' == label" class="sr-only">{{ label }}</span>
		</template>
		<template #td="{ item }">
			<td data-title="employer_name">{{ item.employer_name }}</td>
		</template>
	</PoTable>
</template>

<script setup lang="ts">
import { ref } from "vue";
import { PoTable } from "@pension/ui-kit";

const tableHead = [{ label: "EmployerName" }];

const tableBody = ref([
	{
		employer_name: "",
	},
]);
</script>
```

### Table with Action Buttons Pattern

When adding actions (Edit, Delete, View) to a table row, wrap the actions in a right-aligned flex container:

```vue
<template>
	<PoTable :thead="tableHead" :tbody="tableBody">
		<template #th="{ label }">
			<span v-if="'Action' !== label">{{ label }}</span>
			<span v-if="'Action' == label" class="sr-only">Actions</span>
		</template>
		<template #td="{ item }">
			<td data-title="Name">{{ item.name }}</td>
			<td data-title="Action">
				<div class="flex items-center space-x-3 justify-end">
					<PoTableAction btn-type="view" @click="viewItem(item)" />
					<PoTableAction btn-type="edit" @click="editItem(item)" />
					<PoTableAction btn-type="delete" @click="deleteItem(item)" />
				</div>
			</td>
		</template>
	</PoTable>
</template>
```

## 5. Page header with Page Status and Buttons

Use this template when building headers with entity status badges and workflow actions.

```vue
<template>
	<header class="lg:flex lg:items-end">
		<PoPageTitle
			class="grow"
			:stand-alone="true"

				v-else-if="employer.status === 'deregistered'"
```

## 6. Batch Actions & Selection Bar

When implementing row-level bulk operations (approving drafts, batch exporting, batch status updates), combine `PoTableCheckbox` with a sticky/top selection banner:

```vue
<template>
	<!-- Bulk Actions Banner (renders when items are selected) -->
	<div
		v-if="selectedIds.length > 0"
		class="bg-sky-50 border border-sky-200 rounded-xl px-4 py-3 flex items-center justify-between"
	>
		<div class="flex items-center space-x-2">
			<span class="bg-sky-600 text-white text-xs font-bold rounded-full w-6 h-6 flex items-center justify-center">
				{{ selectedIds.length }}
			</span>
			<span class="text-sm font-medium text-sky-900">Items Selected</span>
		</div>
		<div class="flex items-center space-x-2">
			<PoButton :label="\`Approve (\${selectedIds.length})\`" action-type="primary" @button-click="batchApprove" />
			<PoButton :label="\`Reject (\${selectedIds.length})\`" action-type="danger" @button-click="batchReject" />
			<PoButton label="Clear" action-type="ghost" @button-click="selectedIds = []" />
		</div>
	</div>

	<!-- Checkbox Column inside PoTable slot -->
	<template #td="{ item }">
		<td data-title="Select" class="w-10">
			<PoTableCheckbox
				:item-id="item.id"
				:is-checked="selectedIds.includes(item.id)"
				@checkbox-clicked="handleCheckboxToggle"
			/>
		</td>
		...
	</template>
</template>
```

# Agentic AI Layout Construction Rules

When an Agentic AI designs or generates layouts using `@pension/ui-kit`:
1. **Always wrap complete pages in `<PoContentArea>`**.
2. **Always structure page headers with `<header class="lg:flex lg:items-end mb-4">`** containing `<PoPageTitle :stand-alone="true" />` on the left and action buttons on the right.
3. **Always use `<PoCard class="p-3 pl-4">`** for the list search/filter/pagination toolbar.
4. **Always wrap `<PoTable>` inside `<PoCard>` with `<template #content>`**, and render `<PoEmpty>` when filtered items are empty.
5. **Always use `<PoTableAction>`** for row-level actions (`view`, `edit`, `delete`, `icon`), never unstyled buttons.
6. **Always format Maldivian currency with `<Rufiyaa :amount="..." />`** and dates with `formatDate(...)`.
7. **Always use `<PoDescriptionList :columns="true">`** for metadata pairs (`<dt>` / `<dd>`).
8. **Always use `<PoStatsBlock>`** for metric cards and `<PoStatusPill>` / `<PoPageStatus>` for badges.
9. **Never use custom prefixes like `po:` in consuming application code** — use standard Tailwind utilities.
